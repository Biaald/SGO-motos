# SGO-motos
O SGO-motos (Sistema de Gestão de Oficinas) é um sistema web simples para gerenciar ordens de serviço, estoque de peças e clientes em uma oficina de motos local. Ele permite cadastro de motos, agendamento de reparos, controle de estoque e emissão básica de relatórios, facilitando o dia a dia de mecânicos autônomos.
